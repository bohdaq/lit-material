# @lit-material/alert

## 0.0.3

### Patch Changes

- 0102a65: Component custom properties for values themes reached through `::part`: button shape and pressed scale, code-block shape, container colour, fonts and line height, alert shape, stat value font.

## 0.0.2

### Patch Changes

- 64593c1: The info, success and warning colour tokens (`--lit-material-alert-*`) can now be set on `:root` or any ancestor. Their defaults were declared on `:host`, which beat inherited values, so theming needed an element selector; they are now `var()` fallbacks.
