# @lit-material/alert

## 0.0.2

### Patch Changes

- 64593c1: The info, success and warning colour tokens (`--lit-material-alert-*`) can now be set on `:root` or any ancestor. Their defaults were declared on `:host`, which beat inherited values, so theming needed an element selector; they are now `var()` fallbacks.
