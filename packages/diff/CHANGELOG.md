# @lit-material/diff

## 0.1.0

### Minor Changes

- 4730393: New package: `lit-material-diff` shows how a text changed, unified or side by side, with unchanged runs folded to a few lines of context; `lit-material-change-list` lists changes by path for structured data; `lit-material-merge-view` puts versions next to a common base for conflicts. `diffLines`, `sideBySide`, `hunks` and `stats` work without a DOM.
